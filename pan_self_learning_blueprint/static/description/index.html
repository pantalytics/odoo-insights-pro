Odoo Self Learning: Blueprint

Map the business, put Odoo over it, and see where the implementation stands

Blueprint describes a company as one model: chains, processes, activities and click paths. In every activity one role does one thing to one Odoo document.

One company map

  • Phases from left to right, roles from top to bottom, the Odoo apps per phase at the bottom.
  • Pick a scenario to draw its numbered test route.
  • Colour by choices (settled or not), by progress or by the ADKAR band of each role.
  • Zoom in for more detail; click an activity to open its side panel.
  • Works with the keyboard, and colour is never the only signal.

Progress per activity

Project tasks point at activities and carry a progress step: Open, Decided, Built, Tested, Trained, Live. An activity is as far as its least advanced task; each scenario shows the share of its activities that are tested. Planned and spent hours are summed from the tasks.

Role members are contacts, so people without a login count too. ADKAR scores are personal; the map shows only a band per role, once at least three people have a score.

An open blueprint format

Import and export the whole model as one JSON file, kept in git if you like. Records match on their code, so importing again updates and never deletes. Loading the bundled template again only adds what is missing.

Getting started

  1. Install the app and give people the Blueprint user or administrator access right.
  2. Open Blueprint, Import / export, Load template.
  3. Open Blueprint, Company map.
