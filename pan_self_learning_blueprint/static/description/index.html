Odoo Self Learning: Blueprint

Map the business, put Odoo over it, and see where the implementation stands

Blueprint describes a company as one model: value chains, processes, activities and click paths. Every activity is the shared key between three pillars: the business (what we do), the system (what Odoo must do) and the people (can they do it). One role does one thing to one Odoo document.

One company map

  • Phases from left to right, following Odoo's document chain.
  • Roles from top to bottom, with external roles (customer, supplier) at the edges.
  • A progress band on top and the Odoo apps per phase at the bottom.
  • Filter by scenario to draw a numbered test route across processes.
  • Colour by choices (proposal, provisional, fixed, revised), by progress or by ADKAR readiness.
  • Zoom in for more detail; click an activity to open its side panel.
  • Click a phase name to see who still needs training in that phase.
  • Clashes (a choice that was revised, or fixed with an open point) are outlined and can be shown on their own.
  • Works with the keyboard, and every colour also has a shape.

Readiness per activity

Project tasks get three fields: a scenario, the activities they move forward and a rung: 0 Open, 1 Decided, 2 Built, 3 Tested, 4 Trained, 5 Live. An activity is as far as its least advanced task, counted over all its tasks so every user sees the same progress; cancelled tasks are left out. Tasks from any project can point at activities, so the map keeps working after go-live.

Planned and spent hours per activity and scenario are summed from the linked tasks. A task on several activities counts for each of them, and once per scenario. Estimates and timesheets stay on the tasks (the module depends on Timesheets, which also installs Employees).

ADKAR scores (awareness, desire, knowledge, ability, reinforcement) per user show whether the people in each role are ready for the change. Scores are personal: users see only their own, administrators see all. The map shows a role's average once at least three of its users have a score, and lists per activity who still needs training.

An open blueprint format

Import and export the whole model as one JSON file. Records match on their code, so a file can be imported again and again and kept in git. A blueprint holds no personal data. Start from the bundled template and adapt it to the company: loading the template again only fills what is missing and keeps the company's own choices, click paths, open points and scenario steps.

Getting started

  1. Install the app and give users the Blueprint user or manager access right.
  2. Open Blueprint, Import / export, Load a template, import or export, and load the template or import your own file.
  3. Open Blueprint, Company map.
