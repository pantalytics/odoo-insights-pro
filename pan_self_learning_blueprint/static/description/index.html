Odoo Self Learning: Blueprint

Map the business, put Odoo over it, and see where the implementation stands

Blueprint describes a company as one model: value chains, processes, activities and click paths. Every activity is the shared key between three pillars: the business (what we do), the system (what Odoo must do) and the people (can they do it). One role does one thing to one Odoo document.

One company map

  • Phases from left to right, following Odoo's document chain.
  • Roles from top to bottom, with external roles (customer, supplier) at the edges.
  • A progress band on top and the Odoo apps per phase at the bottom.
  • Filter by scenario to draw a numbered test route across processes.
  • Colour by choices (proposal, provisional, fixed, revised), by progress or by ADKAR readiness.
  • Zoom in for more detail; click an activity to open its side panel.

Readiness per activity

Project tasks get three fields: a scenario, the activities they move forward and a rung: 0 Open, 1 Decided, 2 Built, 3 Tested, 4 Trained, 5 Live. An activity is as far as its least advanced task. Tasks from any project can point at activities, so the map keeps working after go-live.

ADKAR scores (awareness, desire, knowledge, ability, reinforcement) per user show whether the people in each role are ready for the change.

An open blueprint format

Import and export the whole model as one JSON file. Records match on their code, so a file can be imported again and again and kept in git. A blueprint holds no personal data. Start from the bundled template and adapt it to the company.

Getting started

  1. Install the app and give users the Blueprint user or manager access right.
  2. Open Blueprint, Blueprint, Import / export and load a template, or import your own file.
  3. Open Blueprint, Company map.
